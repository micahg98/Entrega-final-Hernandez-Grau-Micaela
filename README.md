# Micaela Hernández Grau — Portfolio

Sitio web de presentación y portfolio de **Micaela Hernández Grau**, diseñadora gráfica, UX/UI y web.

🔗 **Sitio publicado:** [https://entregafinal-pied.vercel.app](https://entregafinal-pied.vercel.app)

## Contexto

Este proyecto es la **entrega final del curso de Desarrollo Web de Coderhouse**. El objetivo es construir un sitio personal que funcione como carta de presentación profesional y como portfolio, mostrando habilidades, proyectos realizados y servicios ofrecidos.

## Páginas

| Página | Contenido |
| --- | --- |
| **Inicio** (`index.html`) | Presentación y proyectos destacados. |
| **Habilidades** (`pages/habilidades.html`) | Formación, herramientas de diseño y desarrollo, y metodologías de trabajo. |
| **Proyectos** (`pages/proyectos.html`) | Casos de diseño: Henko, Flexy e Irupé. |
| **Servicios** (`pages/servicios.html`) | Diseño UX/UI, diseño gráfico y diseño web. |
| **Contacto** (`pages/contacto.html`) | Datos de contacto. |

## Tecnologías

- HTML5 semántico
- CSS3 con **Sass (SCSS)**, organizado en `base`, `components`, `layout` y `utilities`
- **Bootstrap 5** (grilla, navbar con offcanvas, carruseles)
- **Bootstrap Icons**
- **AOS** y **Animate.css** para animaciones
- Diseño responsive
- Publicado en **Vercel**
